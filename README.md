Hi this is my CLI game **Banish The Horror** which I made for the Hack Club ysws **Bashed 2026** event :D  
This was coded on mac so please let me know if any compatability issues arise
It is an eldrich themed speed typing game written entirely in Bash. Type the incantations before the timer runs out, or lose your sanity as the horror creeps through...  
To run a bash script, you clone the repository, make the script executable, and run the game.
